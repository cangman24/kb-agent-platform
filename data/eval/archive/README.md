# 历史 Agent 评测任务

此目录保留原双项目仓库的 150 条任务，分为单步、双步、三步各 50 条。
可在仓库根目录运行 `python tools/gen_legacy_agent_tasks.py --out <临时文件>` 复现其内容。

这些任务的知识问题涉及 NDRE、NDVI 等遥感主题，工单编号涉及 T-100 至 T-149 及 T-200 至 T-249。
当前独立 Agent 使用运维制度知识库和少量演示工单，无法直接满足这些任务的知识和记录前提。
此归档用于追溯原评测口径，使用前需要适配知识主题、实际工单、期望工具顺序和答案断言。

当前演示集为 `data/eval/demo_agent_tasks.jsonl`，共 5 条。
真实模型评测可用 `python demos/live/demo_agent_eval_real.py --tasks <任务文件>` 指定经过适配和人工复核的任务集。
本次迁移保留旧任务内容，尚未对 150 条任务作当前业务适配或重新测评。
